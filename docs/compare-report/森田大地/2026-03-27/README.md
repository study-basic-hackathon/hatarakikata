IQR が最も大きいのは **stage5**（IQR: 6.45）。
分布が広いほど、類似・非類似を区別する識別力が高い。

最高類似度が最も高いのは **stage5**（95.34%）。
最高値と中央値の差が大きいほど、上位マッチが明確に際立っている。

- stage1: 最高 88.38% − 中央値 74.86% = 差 13.52
- stage2: 最高 90.01% − 中央値 77.70% = 差 12.32
- stage3: 最高 90.44% − 中央値 78.20% = 差 12.24
- stage4: 最高 91.07% − 中央値 80.89% = 差 10.18
